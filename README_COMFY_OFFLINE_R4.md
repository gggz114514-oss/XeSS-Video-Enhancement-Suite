# R4 ComfyUI 节点

当前安装、使用与限制统一见 [README](README.md)。本版替换旧节点，不再采用本地并列试用安装器。

三种注册名：`XeSSR4OfflineSuperResolution`、`XeSSR4OfflineFrameGeneration`、`XeSSR4OfflineSuperResolutionFrameGeneration`。

输入原生文件型 VIDEO，返回 VIDEO 和成片路径。通过 Git 更新后正常重启 ComfyUI，自动安装匹配的运行时；旧工作流请替换节点。细节见 [升级与回退](docs/COMFY_R4_UPGRADE.md)。
